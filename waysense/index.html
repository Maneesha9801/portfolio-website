The Design Problem

GPS fails indoors. For large complexes like malls or multi-level parking lots, this creates a "last-mile" navigation gap. Users can drive to the mall, but they can't find their way inside it.

Existing solutions like BLE Beacons require installing thousands of battery-powered devices (high maintenance). LiDAR/Camera systems are privacy-invasive and computationally expensive.

"How might we build a navigation system that requires ZERO new hardware installation?"

Key UX Decisions

1. The "Blue Dot" Confidence

Challenge: Wi-Fi signals fluctuate, causing the dot to "jump."

Fix: We implemented a "Hysteresis Filter" (smoothing algorithm) so the dot glides instead of teleports, preserving user trust.

2. Battery Optimization

Challenge: Continuous Wi-Fi scanning drains battery.

Fix: Adaptive scanning—we scan frequently (every 1s) when the user is moving fast, and slow down (every 5s) when they stop.

The Engineering

We approached this as a Signal Processing problem. We built a Digital Twin of the campus—mapping every physical coordinate to a vector of Wi-Fi signal strengths.

Engineering Decision Matrix

Comparative analysis of positioning technologies for indoor navigation.

Option A: BLE Beacons

High Friction

Requires installing thousands of battery-powered beacons. Maintenance nightmare.

Constraint

Requires users to keep Bluetooth ON. High battery drain perception.

Rejected

Option B: Wi-Fi RTT

Precision

Superior 1-2m accuracy using Time-of-Flight. The "perfect" engineering solution.

Critical Flaw

Hardware limitation: Only works on Android 9+ and requires expensive RTT-enabled routers.

Rejected

Selected: WaySense

Accessibility

Works on 99% of smartphones. No specific hardware required on the user side.

Infrastructure

Utilizes existing standard Wi-Fi Access Points. Low implementation cost.

Trade-off

~5m precision. Acceptable for vehicle wayfinding contexts (car size > 2m).

Final Choice

Reflection

What I Learned

  • ✓Constraints Breed Creativity: Not being allowed to buy hardware forced us to squeeze every bit of utility out of existing Wi-Fi signals.
  • ✓User Trust is Fragile: If the blue dot jumps across the map just once, the user stops trusting the app. Smoothing algorithms are as important as positioning algorithms.
  • Next:I'd like to integrate Sensor Fusion (Accelerometer + Gyroscope) to enable "Dead Reckoning" for even smoother navigation between Wi-Fi scans.
